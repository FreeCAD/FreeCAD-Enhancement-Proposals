# FreeCAD Enhancement Proposals

This repository contains FreeCAD Enhancement Proposals (FEPs) that are used to discuss any substantial changes to FreeCAD.

## FEP Process
See Proposal [FEP-0001: FEP Process](./FEPs/FEP-0001-process/README.md) for a complete description of the FEP process, including how to create a new proposal.
